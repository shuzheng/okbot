# Security Policy

## Supported versions

Security fixes land on the current `main` branch of this repository. Older release tags are not maintained as separate security branches unless a release note says otherwise.

## Reporting a vulnerability

Please **do not** file a public GitHub issue for security vulnerabilities.

Prefer **GitHub private vulnerability reporting** for this repository:

1. Open the repository on GitHub
2. Use **Security → Report a vulnerability** (private advisory), when enabled for the repo
3. Include impact, reproduction steps, affected version/commit, and any suggested fix

If private vulnerability reporting is unavailable on the repository settings, contact the maintainer through the GitHub profile / email associated with recent commits on `main` (see `git log`), and mark the message as a security report. Do not invent or publish alternate security inboxes.

We will acknowledge reports as capacity allows and coordinate disclosure after a fix is ready.
