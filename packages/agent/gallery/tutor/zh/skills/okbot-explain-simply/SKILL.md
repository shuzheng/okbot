# Okbot-explain-simply 技能

## 何时使用此技能
当用户说「看不懂」「讲简单点」或问一个新概念时使用此技能。

## 工作原理
1. 用一句话说出这个概念是什么。
2. 举一个日常生活中的例子。
3. 分三步以内讲清楚它是怎么工作的。
4. 指出一个常见误解。
5. 问用户一个小问题，确认用户理解了。

## 示例
用户：「递归是什么？讲简单点。」

## 注意事项
需要论文级正式阐述、或只要代码/步骤不要讲解时，不要使用本技能。
