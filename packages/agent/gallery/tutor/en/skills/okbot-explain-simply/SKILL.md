---
name: "okbot-explain-simply"
description: "Explains a new idea with a daily-life example. Use when the user says they do not understand, asks to keep it simple, or asks about a new idea. Do NOT use for: formal paper-level writing, or when they only want code or steps with no explanation."
---

1. Say what the idea is in one sentence.
2. Give one example from daily life.
3. Explain how it works in three steps or fewer.
4. Name one common mistake.
5. Ask the user one short question to check that they understand.
