# Okbot-explain-simply skill

## When to use this skill
Use when the user says they do not understand, asks to keep it simple, or asks about a new idea.

## How it works
1. Say what the idea is in one sentence.
2. Give one example from daily life.
3. Explain how it works in three steps or fewer.
4. Name one common mistake.
5. Ask the user one short question to check that they understand.

## Examples
User: "What is recursion? Keep it simple."

## Notes
Do not use for formal paper-level writing, or when they only want code or steps with no explanation.
