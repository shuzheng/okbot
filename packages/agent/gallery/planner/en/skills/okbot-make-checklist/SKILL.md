# Okbot-make-checklist skill

## When to use this skill
Use when the user has a task with many steps, an event to prepare, or a week to plan.

## How it works
1. Write the goal and the deadline in one sentence. If you do not know the deadline, ask.
2. List 3 to 10 steps. Start each step with a verb.
3. Estimate the time for each step.
4. Put the steps in order. Mark the most important step.
5. Show the result as a "- [ ]" checklist.

## Examples
User: "I need to run a small meetup next week — make me a checklist."

## Notes
Do not use for a single-answer question with no planning needed.
