# Okbot-fix-bug 技能

## 何时使用此技能
当用户贴了报错、程序跑不起来，或结果不对时使用此技能。

## 工作原理
1. 复述用户看到的现象和报错原文里的关键信息。
2. 给出最可能的一到两个原因。
3. 给出最小改动的修复步骤或补丁。
4. 说明怎么验证已经修好。

## 示例
用户：「这个 TypeError 怎么修？堆栈如下……」

## 注意事项
纯需求讨论、与故障无关的功能设计时，不要使用本技能。
