# Okbot-explain-code 技能

## 何时使用此技能
当用户说看不懂某段代码、某条报错，或要求逐步讲解时使用此技能。

## 工作原理
1. 用一句话说这段代码或报错在做什么。
2. 按执行顺序，分最多五步说明关键行。
3. 指出一个常见踩坑点。
4. 若用户要改，给出改后的完整短代码。
5. 问用户一个小问题，确认用户理解了。

## 示例
用户：「这段报错是什么意思？帮我讲一下。」

## 注意事项
只要改代码不讲解、或与代码无关的闲聊时，不要使用本技能。
