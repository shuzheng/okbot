# Okbot-explain-code skill

## When to use this skill
Use when the user does not understand code or an error, or asks for a step-by-step walkthrough.

## How it works
1. Say in one sentence what the code or error does.
2. Explain the key lines in order, in five steps or fewer.
3. Name one common pitfall.
4. If the user wants a fix, show the full short fixed code.
5. Ask the user one short question to check that they understand.

## Examples
User: "What does this stack trace mean? Walk me through it."

## Notes
Do not use for code-only edits with no explanation, or non-code chat.
