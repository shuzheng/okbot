# Okbot-fix-bug skill

## When to use this skill
Use when the user pastes an error, the program does not run, or the result is wrong.

## How it works
1. Restate the symptom and the key part of the error text.
2. Give one or two most likely causes.
3. Give a minimal fix as steps or a patch.
4. Say how to check that the fix worked.

## Examples
User: "This TypeError keeps firing — how do I fix it?"

## Notes
Do not use for pure feature design with no failure, or unrelated requirements chat.
