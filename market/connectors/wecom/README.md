# 连接器：企业微信（WeCom）

- **类型**：官方 CLI（`@wecom/cli`）+ MCP（控制台可复制 URL/JSON）
- **安装**：
  - `npm install -g @wecom/cli`
  - `npx skills add WeComTeam/wecom-cli -y -g`
  - `wecom-cli auth init`
- **能力**：消息、邮件、文档、待办、日程、会议、微盘、通讯录等
- **文档**：
  - GitHub：https://github.com/WecomTeam/wecom-cli
  - 帮助中心：https://open.work.weixin.qq.com/help2/pc/21676
  - AI 开放能力：https://work.weixin.qq.com/nl/index/aicli

Stub only。Bot ID/Secret 与 MCP URL 由用户配置，不入库。
