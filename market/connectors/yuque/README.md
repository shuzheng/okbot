# 连接器：语雀（Yuque）

- **类型**：官方 MCP（stdio，`yuque-mcp`）
- **安装**：`npx yuque-mcp install --token=YOUR_TOKEN --client=cursor`
  - 团队空间 / 私有部署加 `--host=https://your-space.yuque.com`
- **运行**：`npx -y yuque-mcp` + 环境变量 `YUQUE_TOKEN`（可选 `YUQUE_HOST`）
- **工具**：19 个（user / search / books / docs / toc / notes / boards）
- **文档**：https://github.com/yuque/yuque-mcp-server
